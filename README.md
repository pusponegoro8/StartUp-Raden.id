🚀 Personal Bio Startup Website

Fitur Lengkap:
- ✅ Modern responsive design (mobile-first)
- ✅ Dark/Light theme (persistent)
- ✅ Smooth animations & scroll effects
- ✅ Dynamic projects dari JSON
- ✅ Contact form + auto WhatsApp
- ✅ Social media showcase
- ✅ SEO optimized untuk Google
- ✅ Fast loading, no backend needed

 Cara Deploy GRATIS (untuk Bio Link):

1. **GitHub Pages** (Recommended)
```
1. Buat repo baru: personal-bio-site
2. Upload semua file kesini
3. Settings > Pages > Source: Deploy from branch main
4. Live di: https://username.github.io/personal-bio-site
```

2. **Netlify** (Drag & Drop)
```
1. netlify.com/drop
2. Drag folder personal-bio-site
3. Dapat URL instant: random-name.netlify.app
```

3. **Vercel**
```
1. vercel.com > New Project > Import Git atau drag folder
2. Live dalam 1 menit
```

4. **Test Lokal**
Buka `index.html` di browser. Copy URL: `file:///path/to/index.html`

Custom:
- Ganti foto: `assets/profile.png` (320x320 recommended)
- Edit projects.json untuk link project Anda
- Update social links di HTML

Hosting siap pakai untuk bio IG/Twitter/FB!

**Live demo lokal:** Buka `personal-bio-site/index.html` di browser Anda sekarang!
